Branche ta console en USB (débogage activé), puis clique « Détecter ».

Connecter la console sans câble

Le Wi-Fi évite le câble, mais reste 2 à 5× plus lent pour les gros transferts. À faire une seule fois : ensuite la console est reconnue toute seule.

1
Sur la console Activer le débogage sans fil

Ouvre Paramètres (l'app Android, pas l'émulateur), puis :

Paramètres → Système → Options pour les développeurs → Débogage sans fil (à activer)
Je ne vois pas « Options pour les développeurs »

Elles sont masquées par défaut. Va dans Paramètres → À propos du téléphone et tape 7 fois sur Numéro de build. Le menu apparaît alors dans Système.

2
Sur la console Ouvrir la fenêtre d'appairage

Dans l'écran Débogage sans fil, touche « Associer l'appareil avec un code d'association ».

Une fenêtre s'ouvre et affiche deux informations : un code à 6 chiffres et une ligne « Adresse IP et port » du type 192.168.1.42:37105.

Laisse cette fenêtre ouverte : le code expire si tu la fermes.

Accès

Qui peut ouvrir la ludothèque, et depuis où.

Authentification

Indispensable dès que la ludothèque est jointe depuis l'extérieur. Le SSO délègue la connexion à ton fournisseur : aucun mot de passe n'est stocké ici.

Les comptes internes sont la voie éprouvée. Le SSO vérifie les jetons avec une implémentation RS256 propre à Romule, sans bibliothèque tierce : elle est testée, mais elle est jeune.

Mode Sans authentification, seul l'accès local est ouvert.
Personnes autorisées Chacune se connecte avec son adresse et son mot de passe. Il n'y a pas de rôles : tout le monde voit la même ludothèque.
Adresse du fournisseur L'issuer OpenID. Authentik : https://auth.exemple.fr/application/o/<slug>/
Client ID Donné par le fournisseur à la création de l'application.
Client secret Laisse vide pour un client public (PKCE seul).
Comptes autorisés Adresses e-mail ou groupes, séparés par des virgules. Vide = toute personne que ton fournisseur authentifie.
Adresse publique Uniquement derrière un proxy. Vide = déduite de la requête.
Réseau et notifications
